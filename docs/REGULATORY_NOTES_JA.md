# 保険比較サービス向け設計上の注意

本書は製品設計上の注意であり、個別案件の法的助言ではありません。実サービス公開前に最新の法令・監督指針を確認してください。

v2は標準状態で特定商品を「おすすめ」「1位」「最適」と自動推奨せず、利用者が同一項目で比較する方式です。画面には比較主体、情報源、利害関係、情報更新日、保険料以外の保障条件、試算前提を表示できるようにしています。

金融庁の監督指針では、商品情報の転載・比較と、報酬を得て具体的な商品の推奨・説明を行う行為では、保険募集・保険媒介への該当性の評価が変わり得ます。個人属性によるおすすめ、商品順位、成果報酬と連動した推奨、申込みへの営業誘導を追加する場合は事前に個別確認してください。

価格だけを過度に強調せず、保障内容、免責、期間、条件、前提等を併記してください。掲載情報と試算ルールの正確性はサービス運営者が管理してください。

v2標準デモは氏名や健康情報を保存しません。病歴等を扱う場合は個人情報保護上の追加設計が必要です。

公式確認先: 金融庁「保険会社向けの総合的な監督指針」「金融サービス仲介業者向けの総合的な監督指針」
